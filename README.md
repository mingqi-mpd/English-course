# 50万南美之旅经费筹集英语课

这是可直接部署到 GitHub Pages 的静态网站文件。

## 部署方法

1. 在 GitHub 新建一个仓库。
2. 把本文件夹中的所有文件上传到仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. Branch 选择 `main`，文件夹选择 `/ (root)`，然后保存。
6. 等待一两分钟，GitHub 会显示网站地址。

首页文件是 `index.html`，基金进度页是 `fund.html`。
